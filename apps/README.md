# Forma UI — Aplicações de Desenvolvimento (`apps/`)

Aplicações isoladas de exploração, documentação interativa e laboratório de acessibilidade (nenhuma delas é dependência de runtime dos pacotes publicados):

- **`apps/docs` (`@forma-ui/docs`)** — Playground comportamental interativo, matriz direcional de teclado (LTR/RTL) e visualizador de design tokens.
- **`apps/storybook` (`@forma-ui/storybook`)** — Workbench em Lit 3 com `@storybook/addon-a11y` cobrindo overlays, formulários, coleções, controles enterprise e fluxos de produtividade.
