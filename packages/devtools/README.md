# @forma-ui/devtools

Opt-in runtime inspector for **Forma UI 50.0.0**. Subscribes to `@forma-ui/core`'s `TelemetryBus` to record controller state timelines, export diagnostic JSON snapshots, and inspect mounted DOM trees for duplicate IDs, dangling ARIA IDREFs, and positive `tabIndex` anti-patterns.

Zero overhead in production unless explicitly imported.
