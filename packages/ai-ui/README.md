# @forma-ui/ai-ui

Headless, accessible interaction controllers for **Generative & Agentic AI Interfaces** in **Forma UI 100.0.0**:
- `createStreamingMessageController`: token/chunk streaming with `AbortController`, throttled ARIA live announcements, and `aria-busy`.
- `createToolApprovalController`: Human-in-the-Loop approval queue (approve/reject/edit arguments + audit log).
- `createCitationController`: inline citation linking to verifiable sources with ARIA relationships.
